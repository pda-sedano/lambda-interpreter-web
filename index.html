How it works

      
The interpreter reduces terms in normal order: at every step it reduces the leftmost, outermost redex first. That strategy is guaranteed to reach a term's normal form whenever one exists, even when some argument would loop forever if evaluated.

      
Internally, terms are stored with de Bruijn indices: each variable is a number counting the binders between it and the λ that binds it. Substitution therefore never captures a variable by accident. Results are printed with your original variable names, adding a scope index such as x^1 only where a name is shadowed.


      
Syntax

      

        
WriteMeaning

λx y z.MShorthand for λx.λy.λz.M.

          
M NApply M to N. Application is left associative: f a b means (f a) b.

          
( … )Grouping.

          
x^nThe x bound n binders further out than the nearest one: in λx x.x^1, x^1 is the outer x.

        
      

      
A λ body is a single term, so λx.x y means (λx.x) y; write λx.(x y) to apply x to y. A variable name can be any run of characters except whitespace and λ . ( ) ^.


      
Limits

      
    
        
  • Each run stops after 1 second (status timeout), or earlier at the max-steps limit if you set one.
    • 
        
  • Terms nested more than 1000 levels deep are refused (status too_deep if a reduction would get there).
    • 
        
  • Long traces show the first and last 100 steps.
